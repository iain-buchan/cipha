# COVID-19 publications and the status of their code

All COVID-19 outputs by the CIPHA group and collaborators with Iain Buchan as an author, newest first, with where the analysis code stands. Status key:

- **in repo**: code in this repository (folder given)
- **held by authors**: the paper says code is available from the corresponding author or on request; not yet public
- **consortium**: analysis run by another consortium; their code is linked in `related-repositories.md`
- **no code**: commentary, review, protocol, qualitative or policy piece with no analysis code to share

## Code still to be gathered

In rough order of value for reuse, the analyses whose code exists but is not yet public:

1. The Liverpool community testing pilot analyses: Innova performance (BMJ 2021), viral load distributions (Euro Surveill 2023), school-aged children (J Public Health 2022), daily contact testing (EClinicalMedicine 2022); R code held by David Hughes, Chris Cheyne and Marta García-Fiñana.
2. SMART Release & Return: the SAP analyses (Cheyne, Burnside, Dodd, Hughes), to sit beside the anonymised data already here.
3. Vaccine effectiveness against Delta (BMC Infect Dis 2022): R with BayesianTools, held by Kieran Sharkey and Karan Pattni.
4. Tiered restrictions and cases (BMJ Open 2022): the companion to the tier 3 hospitalisations script already here.
5. The SAVI model (JECH 2021) from Konstantinos Daras.
6. Events Research Programme (J R Soc Med 2023) and shielding mortality (Public Health 2023).
